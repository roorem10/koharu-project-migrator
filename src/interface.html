    Where are my projects?

    Older chapters are usually in Documents → Koharu or OneDrive → Documents → Koharu. You can also scan a backup, another drive, or a single .khrproj folder. Newer .khr files in the scanned folder appear as already current. If your browser asks to “upload” a folder, the selected source files are read locally.

    On Windows, paste %LOCALAPPDATA%\Koharu\projects into File Explorer to check the usual per-user location. For a custom install, open Koharu and rescan in the Windows launcher to find its projects folder. On Linux the usual output location is ~/.local/share/Koharu/projects/. On macOS it is ~/Library/Application Support/Koharu/projects/.

    What gets converted?

    Close the chapter in the old Koharu before converting. The migrator checks the saved data, recovers the newest intact revision, and preserves the original folder. Scans, page order, editable text, groups and paint carry over. Old page-wide cleanup stays editable as a page layer. Full-page masks are kept in the hidden Legacy data group. Text can wrap differently in the new editor. Provider settings are configured separately in Koharu.

    Keep this window open until saving finishes. Large books need enough memory to hold the finished project. The shareable summary contains counts. The detailed report lists pages and anything to review.

    About and licenses

    Independent offline utility for Koharu issue #1406. Based on the 0.83.5 and 0.85.6 project formats. Includes sql.js, SQLite, noble-hashes and fflate.
